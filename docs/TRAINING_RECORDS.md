# 训练记录保留约定

每次新训练必须在启动前接入记录，保留：不可变的配置与完整命令、代码commit或SHA256、包与硬件信息、数据集清单、归一化和机器人映射；原始stdout/stderr、原生TensorBoard（存在时）、JSONL/CSV结构化loss/分量/LR/梯度范数/耗时；可读曲线及真实记录频率和数值精度。

记录位于records而不是checkpoint中。清理权重不能删除指标、曲线、配置、attempt、恢复和抽样预算证据。重启attempt与生产训练、benchmark分开，曲线保留原始历史后再生成活跃谱系，不能插值虚构没有打印的历史值。

现有OpenPI/Kuavo训练使用原kuavo记录入口。不能为了补记录或改显示名重启活跃GPU训练；先用CPU补导出已有记录，再在下一次启动接入。训练GPU进程显示为 `.venv/bin/python`，使用原环境和原始参数，完整命令保存在记录中。

本轮项目部署和评测不会自动启动额外训练。所有训练launch需要单独明确授权GPU和预算。不得把密码、token、私钥或整个环境打进归档。

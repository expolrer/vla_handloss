# 研究计划

## 问题

在固定50条示范和RGB输入下，改善末端灵巧手建模是否比统一动作头更有效？结构收益、参数增量收益和损失再分配收益应分开验证。

π0.5的action expert特征先经过原始动作投影。B1/B3另加 `Linear → GELU → Linear` 残差，只写入40个手部维度。残差输出层零初始化，初始行为不因额外随机输出而改变。C0将残差写入全部动作维度，宽253作为近似参数匹配对照；真实参数量以训练审计记录为准。

## 损失

损失是归一化动作空间中的flow-matching速度误差，不是直接关节角MAE或成功率：

```text
L = [sum(arm squared error) + lambda * sum(hand squared error)]
    / [arm_dim + lambda * hand_dim]
```

λ=1为逐维等权，λ=2提高每个手部维度的权重，不是把训练步数加倍。因双手占40维，基线本已偏重手部。C1令 `lambda=arm_dim/40`，使手臂与手部两个组总权重相等。

原生记录保留 `loss / loss_unweighted / loss_hand / loss_arm`；不同λ的加权loss不能直接用来排名。统一比较未加权误差、两个分组误差、相同预算学习曲线和在线部署指标。

## 预算与阶段

1. 两任务×八条件，单种子42，各10,000更新、相同50条示范、batch32、FSDP4。
2. 原始记录不补造未打印的loss；续训分开保存attempt，再生成当前checkpoint谱系曲线。
3. 部署权重、统计量、主动关节映射和固定prompt一起校验，先做一次控制smoke。
4. 每条件先进行50轮官方 `none` anchor匹配在线评测；运行错误不进入成功率分母。
5. 用expert replay与可视化检查成功判定，特别是拼图原始success标志与视觉完成状态不一致的问题。
6. 补齐资产和协议审计后，扩展Cov、Inv和Full通道；之后再设计ACT、触觉或RL改进。

## 证据边界

单种子、训练匹配anchor和50轮部署不能证明跨训练种子、跨任务或真实机器人的泛化优势。增加训练步数并不能消除随机种子误差。应报告实际轮数、配对seed、成功率区间、阶段进展和手部动作质量，而不把注意力或训练loss当成功率替代物。
